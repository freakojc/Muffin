# 笔记链接与返回导航

在实时编辑模式中，Ctrl+点击链接，或右键选择“打开链接”。本地 `.md`、`.markdown`、`.mdown`、`.mkd`、`.mkdn`、`.mdwn` 笔记在 Muffin 标签页内打开；已经打开的文件复用原标签页。网页、其他文件和附件仍使用系统默认应用。

支持相对路径、绝对路径、文件 URL，以及 URL 编码的中文或空格。例如：

```markdown
[方案](方案.md)
[会议记录](会议%20记录.md#议题一)
[本页小节](#实施计划)
[英文标题](#hello-world)
```

标题锚点使用标题的可见文字，英文转为小写，空白变为 `-`，忽略标点；中文保留。重复标题依次使用 `标题`、`标题-1`、`标题-2`，并避开已有锚点。也接受直接填写完整标题文字的片段。找不到文件时留在原页；文件存在但标题不存在时打开文件并显示提示。`[TOC]` 和脚注跳转也能返回。

“编辑 → 后退 / 前进”、Alt+← / Alt+→，以及实时编辑视图中的鼠标侧键，可返回跳转前的位置。实时编辑右键菜单也会显示可用的导航。历史保留选区、编辑模式和阅读位置；关闭的笔记可以重新打开。历史仅保留在当前窗口，本轮关闭应用后不保留导航历史；标签页本身仍沿用原有会话恢复机制。

在侧栏重命名、右键“移动到”，或使用“文件 → 移动到”时，Muffin 检查打开的目录；没有对应的打开目录时，检查文件所在目录。移动后的相对链接会重新计算，既更新其他笔记指向它的链接，也保持被移动笔记的图片和附件目标不变。文件夹内互相引用的相对地址不会无故改写。

有受影响链接时，会列出文件、链接数量和发生改动的行。可取消勾选文件，选择“更新链接”“仅重命名 / 移动”，或取消整个操作。更新范围包括 Markdown 内联链接、引用定义和 Markdown 图片，不处理代码、普通文字中的路径、HTML 链接与 HTML 图片、Wiki 链接或反向链接。

未保存笔记只在编辑器内更新，保留草稿，并作为一次可撤销操作；已保存的文件在磁盘上更新，保留编码、BOM 和换行格式，原始文件备份到应用数据目录的 `note-link-updates`。每次备份包含原文、校验日志和 `rename.json` 路径映射。预览后内容发生变化会中止操作；更新失败会尝试恢复已写入的文件，恢复失败时显示备份位置。

检查范围不包括目录外的笔记，默认略过隐藏目录、构建输出、依赖目录及符号链接。被移动项本身会额外检查。不可读、超过 8 MB、编码无法无损回写、冲突或正在加载的文件会列为跳过项；扫描或预览总量超限时禁用链接更新。选择仅改路径或跳过文件后，相应链接需要手动维护。外部软件或系统文件管理器发起的重命名不会触发此预览。
