# 基础编辑连续操作验收

这轮验收以真实窗口和编辑控件串起操作，正文、选区、历史记录和阅读位置都参与断言。用例位于 `tests/app/DocumentTabsTest.cpp`，随完整 CTest 套件运行，也可用 `MuffinDocumentTabsTest.exe --editing-workflow` 单独执行。

2026-10-21 本地验证：Release 完整构建成功，`ctest --preset conan-release --output-on-failure` 的 343 项测试全部通过，`dist` 目标打包成功。

## 本轮修复

1. 源码编辑按 Tab 时，Qt 原先会先执行焦点切换，导致正文中的制表符插入分支根本没有收到按键。现在普通 Tab 由编辑器处理，Ctrl+Tab 仍交给窗口切换文件。
2. 源码编辑选中文字后插入链接，原先会用 `[](url)` 覆盖文字。现在保留选中文字作为链接标签，整次操作可一次撤销。
3. 实时编辑替换或删除选区后，撤销原先只恢复文字和一个光标。现在同时保存并恢复原选区及方向，选区替换也不会与相邻输入合并。
4. 链接、下划线、清除格式的适用条件提前反映在菜单状态中，禁用项通过菜单悬停提示和状态提示说明操作方式。表格中的单个单元格可使用行内格式。

## 自动化覆盖

| 场景 | 核对内容 |
| --- | --- |
| 中文输入预编辑、提交、取消 | 预编辑不写入正文；取消不产生撤销记录；提交只写入一次 |
| 中文和 emoji 选区替换 | 正向、反向选区均保留完整 UTF-16 字符；撤销恢复文字和选区方向 |
| 输入 → 跨段落剪切 → 粘贴 → 列表缩进 | 每一步核对完整 Markdown 和剪贴板内容，正文不靠重新打开或重置来恢复 |
| 连续撤销、重做 | 分别恢复输入、剪切、粘贴、缩进；替换与随后输入保持独立 |
| 切文件再回来 | 未保存文字、编辑模式、选区、视口锚点及各文件撤销记录相互独立 |
| 完整流程后的全选删除 | 包含列表、标题、引用、格式、链接、表格和代码块的文档删空，撤销和重做均精确恢复 |
| 菜单限制 | 跨段落、跨单元格、代码块、源码多行选区提前禁用；有效选区恢复可用并清除旧提示 |
| 表格与列表内链接 | 单个单元格内插入链接不改变相邻单元格；列表文本可使用单块命令 |
| 切换语言与文件 | 禁用原因跟随当前文档、选区和界面语言更新 |

连续编辑和中文替换两组用例都覆盖实时编辑、源码编辑，以及正向、反向选区。源码中的 Tab 核对制表符插入，实时编辑中的 Tab 核对列表层级调整。

## 当前行为与边界

- 实时编辑的链接、下划线仍要求一个可编辑文本节点内的选区，例如单段落、列表正文或单个表格单元格；跨段落和跨单元格不支持。
- 源码链接支持光标和单行选区；多行选区不直接包成一个 Markdown 链接。
- 清除格式作用于光标所在段落或单元格。选中文字时禁用，避免影响选区以外的格式。
- 下划线、清除格式在源码模式下提示切换到实时编辑。

## 实机输入法验收

自动化通过 Qt 输入法事件验证预编辑、提交和取消，不等同于操作 Windows 输入法候选窗。发布前仍应在打包程序上使用实际中文输入法走一遍：

1. 在段落中间、列表和表格里输入中文，翻页选候选词，用 Esc 取消一次。
2. 跨段落反向拖选并剪切、粘贴，连续用 Tab / Shift+Tab 调整实时编辑列表层级。
3. 撤销、重做数次，切到另一个文件，再回到原文件继续输入。
4. 在长文档中保持阅读位置，反复开关侧栏；在长代码块可见位置点击、选字、输入、撤销。

需观察候选窗位置、输入中是否误触快捷键、光标及选区是否可见，以及是否有明显停顿。这些体感项目应与正文和历史记录的自动化断言一起验收。
