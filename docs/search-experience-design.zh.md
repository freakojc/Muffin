# Muffin 目录搜索与快速定位设计建议

状态：三步首版已实现，Release 构建与回归验证已完成。以下设计记录了取舍；落地范围见下表。2026-10-19。

| 阶段 | 已实现 |
| --- | --- |
| 目录文件定位 | Ctrl+P 后台递归扫描；文件名及父路径；多词、路径段、字符子序列匹配；仅打开目录时可用；复用标签页；文件树右键全部展开和已有全部收起 |
| 跨文件内容搜索 | 搜索侧栏；Ctrl+Shift+F；大小写/正则；分组、源码行号、上下文高亮；优先搜索未保存缓冲区；正文优先在实时编辑中选中，隐藏/不可精确映射命中临时切源码 |
| 带预览和恢复的目录替换 | Ctrl+Shift+H；可勾选文件清单与修改前/后文本预览；明确显示范围和改动数；写入前检查；原子保存、原始字节备份、跨启动恢复；同步所有窗口中的干净标签页 |

首版边界：只搜索偏好设置允许的文本扩展名；不含隐藏项、符号链接/目录联接及常见构建/缓存目录。单文件最多 8 MiB，文件索引最多 20 万项，最多 1 万处命中，保留的匹配文件原文预算为 64 MiB；未完成或达到资源限制的结果不能用于目录替换。未保存、冲突、混合换行及不能无损编码的文件不参与批量写入。尚无 glob 和拼音首字母。预览为文件修改前/后的文本，尚无逐行 diff。备份保存在应用数据目录的 `directory-replacements`，可从“编辑 → 查找和替换 → 撤销文件夹替换”打开恢复入口；当前不自动清理。

原有会话恢复继续保留标签页、目录和展开状态；搜索按目录记忆大小写和正则开关，搜索词和替换计划不会在重启后自动执行。侧栏顶部保留“文件、大纲”，搜索入口改为文件工具栏最右侧的放大镜。点击后以搜索内容替换文件树，放大镜保持可见并高亮；再次点击或点击“文件”返回文件树，保留搜索词、结果和文件树展开状态。Ctrl+Shift+F 仍可直接进入搜索。搜索页移除了目录名、包含/排除路径和底部恢复按钮，旧路径过滤条件不再生效。根目录文件只显示文件名，子目录文件补充父路径；窄结果行围绕命中截取上下文。Ctrl+P 同样只在需要时显示父路径，并使用与选中背景配对的主题文字颜色。下文的附件定位、可调忽略规则、路径筛选、历史和索引监听等仍属于后续设计。

内容搜索跳转优先沿用实时编辑模式：正文、标题、列表、引用、表格和普通代码块中的可见文字可直接选中并滚入视口；链接地址、图片语法、公式和其他不能精确映射的范围临时显示源码，并在状态栏说明。下一次普通正文命中会返回实时编辑。用户手动选择的源码模式继续保留；搜索造成的临时切换不会成为新标签页或重启后的默认模式，定位后及时保存会话状态。

## 判断

值得增加。跨文件找内容、按路径找文件和安全批量替换，直接服务于整理 Markdown 笔记，与 Muffin 的目录侧栏、多标签页和会话恢复相衔接。

建议采用两个互通入口：`Ctrl+P` 快速打开弹窗，`Ctrl+Shift+F` 侧栏内容搜索。统一目录索引、路径显示、历史和跳转逻辑。主入口使用明确名称，不要求用户学习前缀语法。

不建议把 Ctrl+F 改成全局搜索，也不建议给 Muffin 增加 VS Code 式整条活动栏。文件定位是短暂的选择动作，内容搜索和替换是需要保留结果的持续任务。

## 推荐界面

### 快速打开：轻量弹窗

- `Ctrl+P` 打开，Esc 关闭并返回原焦点；方向键选择，Enter 打开；已打开文件切换到现有标签页。
- 结果第一行文件名，第二行相对于当前根目录的路径；同名文件的父路径不可省略。超长路径优先保留能区分结果的部分，悬停可看完整路径。
- 空输入显示当前目录内最近访问文件；没有打开目录时保留“已打开文件 / 最近文件”能力，明确标注来源。
- 有根目录时默认只查该目录及子目录，根目录外的最近文件单独标为“目录外最近文件”，不混入普通结果。
- 只打开目录、还没有打开文件时，也能使用 Ctrl+P。扫描中已有候选可以先出现。
- 默认包含 Markdown 和偏好设置允许的文本扩展名；附件定位可以显式切换为全部文件，只索引文件名，不读取附件内容。
- 可提供“在目录内容中搜索此文本”动作，将输入带到侧栏。首版不必增加 `file:`、`content:` 等前缀。

### 内容搜索：由文件工具栏切换

保留侧栏顶部的「文件 / 大纲」，文件工具栏增加放大镜，切换文件树和内容搜索。搜索时仍选中「文件」，高亮放大镜；文件创建、排序等工具暂时隐藏，保留放大镜用于返回。搜索页从上至下为：

1. 当前根目录/子目录范围；文件树目录右键支持“在此目录中搜索”。
2. 搜索框；大小写、正则选项。整词开关可以后续加入，并为中文明确边界定义。
3. 默认折叠的替换行；展开后出现替换文本和“预览替换”。
4. 默认折叠的路径筛选：包含路径、排除路径、文件类型。
5. 结果概况，例如“3 个文件，7 处匹配”；扫描未完成或被截断时明确显示状态。
6. 按文件分组的结果树：文件名、相对父路径、匹配数；子项显示源码行号、上下文片段及命中高亮。

文件、搜索和大纲共用当前侧栏宽度，拖动范围统一为 220–480px。切换面板和通过快捷键进入搜索时不主动改宽，也不重播已经可见侧栏的打开动画；隐藏后重新打开仍沿用之前的宽度。搜索行适应窄侧栏，实际可用宽度仍需让出编辑区的最小空间。

单击命中打开/激活文件并定位；搜索结果保留，便于连续浏览。方向键浏览、Enter 打开、F6 切换搜索区和编辑区。点击结果不能丢失任何未保存编辑。

第一版可使用正常标签页，不必同步引入复杂的临时预览标签页机制。

### 统一搜索面板的备选方案

也可以在同一侧栏内用「文件 / 内容」切换，Ctrl+P 进入文件模式，Ctrl+Shift+F 进入内容模式。两种模式分别保留查询，替换仅在内容模式出现。

优点是 UI 组件更统一；代价是找文件也会改变侧栏和编辑区宽度，并挤掉上次内容结果。对当前 Muffin 更推荐弹窗与侧栏分工，底层和视觉规则共享。可在使用反馈后考虑“将文件搜索固定到侧栏”。

## 匹配语义

### 文件与路径

- 大小写默认不敏感；统一输入中的 `/`、`\`，匹配根目录相对路径，防止根目录名称导致所有文件误命中。
- 空格分隔的词采用 AND：每个词都必须在相对路径中命中，可跨目录段；例如“学习 单词”。不要求空格两边原样相连。
- `/` 表达路径段顺序，可以跳过中间层；`04/单词` 可命中 `04.学习/英语/单词.md`。单段优先精确/前缀/连续匹配，再考虑模糊匹配。
- 文件名支持按顺序的字符子序列：`朝路` 可以命中 `朝圣之路.md`；连续命中、文件名命中、段首命中优先，跨度大则降权。
- 相关性优先，最近访问只作为相近分数的排序依据；排序稳定，避免结果随异步返回不断跳动。
- 拼音首字母是独立能力，不能由普通子序列算法自动得到。`zs` 匹配“朝圣之路”需要转写索引、首字母子序列匹配及多音字策略；建议后续支持，低于直接中文命中的排序，先限定常用读音，再按反馈扩展。
- 上述规则定义组合优先级：先按空格分词，再按斜线解释有序路径段，每段内部执行连续或子序列匹配。完整路径粘贴需单独识别为路径打开，避免空格路径被误拆。

### 正文

正文首版支持字面匹配和显式正则，与现有 DocumentSearch 保持一致。拼音、模糊匹配不用于正文替换，避免替换范围难以预测。链接格式转换等操作可以使用正则捕获组；目前替换实现支持 `$1` 和 `\1`，新入口保持相同语法。

正文默认搜索 Markdown 源码，包括链接目标、front matter 和代码块。结果行号也是源码行号。命中在渲染模式不可直接表示的隐藏语法（例如链接 URL）时，应进入源码模式选中对应范围，而不只是滚动到附近段落。

跳转模式：标题、正文、列表、表格、链接文字和普通围栏代码中的可精确映射范围优先在实时编辑页选中并滚动到可见位置。链接目标、图片/公式、跨节点范围和零宽等无法精确选中的命中临时切源码，并在状态栏说明原因；随后选择可见正文自动返回实时编辑。手动启用的源码模式继续保留。搜索触发的临时源码模式不写入全局偏好，也不作为下次启动或新标签页的默认模式。

## 替换流程

当前文件：保留 Ctrl+H 和编辑器撤销习惯。搜索页也可提供明确标注的“仅当前文件”范围；不能把当前文件替换按钮与全目录替换按钮做成同一含糊动作。

目录替换：输入替换文本 → 预览 → 确认执行。预览本身就是确认界面，不再连续堆叠多个确认弹窗。

预览须展示：根目录、包含/排除条件、查找与替换文本、选中文件数和匹配数；文件清单可勾选，选择文件可看逐行修改前后差异。执行按钮使用“替换 3 个文件中的 12 处”，避免只写“全部替换”。

### 第一版数据规则

- 搜索优先使用目录内已打开文件的内存内容，结果注明“未保存”；未打开文件从磁盘读取。
- 目录替换预览显示未保存文件，但禁选并提示“先保存后纳入”；允许用户取消、仅处理其他文件，或保存后重新生成预览。其他 Muffin 窗口中的未保存文件同样处理。
- 当前文件替换仍可直接改内存并正常撤销。首版不混用“部分改磁盘、部分仅改缓冲区”的批量提交语义。
- 生成预览时记录路径身份、文件摘要/版本、原格式；执行前重验，发生外部修改、重新编辑、重命名或查询变化则使相关预览失效，需要重算并再次确认。不能对新文本应用旧偏移。
- 单文件使用原子写入，保留编码、BOM、换行和文件末尾状态；编码不能无损处理时跳过并说明。不能顺便重新格式化文档或受“新增末尾换行”的偏好影响而扩大改动。现有 FileController 将内部换行统一为 LF 后按单一格式写回；批量替换不能原样照搬，需要保留原始换行映射，或在首版明确跳过混合换行文件，避免修改无关行。
- 已打开的干净文件通过文档协调层更新，处理文件监视、自写入识别、解析、光标和多窗口一致性。不能绕开 DocumentSession 直接写盘后让旧缓冲区继续保存。
- 每次操作保留原始字节备份和操作清单，提供独立的“撤销上次目录替换”；恢复前核对替换后的摘要，用户后续修改过的文件不强行覆盖。备份保存在应用数据目录，设置保留/清理策略，不散落到笔记目录。
- 跨文件不是一个文件系统原子事务；执行在文件边界可取消，结束报告成功、失败、冲突和跳过清单，可恢复已完成部分。不要承诺全目录“同时成功或同时失败”。
- 搜索结果可以分页或限制展示，替换计划必须基于完整重新扫描，不能只替换已展示的前若干条。扫描未完成时执行按钮禁用。

## 范围、响应和异常状态

- “全局”明确指当前打开的目录，递归包含子目录；只有单文件时保留当前文件搜索，并提供“打开目录以搜索更多文件”。不默认扩展到整块磁盘。
- 路径过滤与正文查询分离：正文输入“术语”，包含路径输入“学习 单词”可复用文件路径匹配器；高级模式另行提供 glob 包含/排除，并明确标注语法，不能让一个输入框暗中切换规则。
- 默认排除 `.git`、缓存、构建和依赖目录，支持查看/调整排除条件；隐藏文件、忽略规则要可解释。二进制和超限文件列入跳过统计。默认过滤的目录和本次扫描异常要分别展示。
- 搜索只读取已允许的文本类型，尊重 FileOpenProtection 的扩展名和大小限制；另设较小的搜索单文件资源预算。特殊大文件通过用户显式纳入后处理，不逐个弹确认框打断查询。
- 不遍历指向目录外的符号链接/目录联接，记录文件身份去重；内部链接的遍历也需有循环保护。
- 文件名索引与文件树展开状态无关。`QFileSystemModel` 按需加载，不能把当前已展开的行当成全部候选。
- 首次扫描在后台、可取消；输入采用短防抖，查询携带代次，丢弃旧结果。正文按文件渐进返回，结果列表使用 model/view 和片段，避免一次创建海量 QWidget。
- 搜索耗时正则不能靠普通线程取消解决；需设资源边界，评估可中止的执行方式或独立 worker 进程，避免恶意/意外回溯持续占用资源。
- 提供：未打开目录、扫描中、无结果、非法正则、权限不足、目录失效、部分结果、跳过文件、文件已变化等明确状态；错误不伪装成“无匹配”。
- 开始不做持久化全文索引，先使用可刷新的内存文件名索引和后台内容扫描，按实际大库性能再决定是否引入其他搜索后端。

## 与展开/收起和状态恢复衔接

现有会话恢复作为基础。增加按目录保存的路径过滤、搜索模式和侧栏宽度；搜索词历史可以关闭/清空。恢复时不自动执行大扫描，不重放替换，也不恢复旧的替换确认计划。

补充“展开当前目录 / 全部展开”和现有“全部收起”放在同一工具组。大树的全部展开需异步、可取消；日常定位依靠搜索结果自动展开当前文件祖先，无需先展开整棵树。用户主动收起后，普通状态刷新不应再次展开；显式点击定位结果才展开对应祖先。

## 建议实现划分

以下是拟新增职责，不表示当前仓库已有这些类：

- `WorkspaceFileIndex`：根目录、递归遍历、排除规则、文件身份、刷新和监听；供快速打开和正文搜索共用。
- `PathMatcher`：多词、路径段、子序列与评分；拼音转写后续作为独立输入特征。
- `WorkspaceSearchService`：任务代次、取消、文件格式解码、打开文档快照、逐批命中；复用/扩展 DocumentSearch 的匹配语义，但避免无上限收集。
- `WorkspaceSearchModel` / `SearchPanelWidget`：文件分组结果、行号/片段、筛选和搜索状态。
- `NavigationTarget`：规范化文件身份、源码 offset/length、文档修订或磁盘摘要；等待异步打开完成后，再验证定位并在需要时切源码模式。
- `WorkspaceReplacePlan` / `ReplacePreviewDialog`：完整不可变预览、文件选择、差异、摘要校验、备份与恢复日志。
- 提取 `FileController` 中可复用的无 UI 文本读写与格式处理；不要为每个文件创建带对话框的打开流程或 Markdown 解析会话。

接入点为现有 `QuickOpenDialog`、`MainWindowFileOps`、`SidebarWidget`、`CommandDeclarations` 和会话保存逻辑。带 `tr()` 的新增/修改 .cpp 必须遵循 AGENTS.md 的 fully-qualified 定义规则；修改翻译时按该文件要求更新。

## 分期与验收
