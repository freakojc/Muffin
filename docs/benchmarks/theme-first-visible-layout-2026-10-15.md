# 主题切换后的首次可见排版（2026-10-15）

本轮按固定阶段测量推进，暂停原生键盘长尾调查。数据与观测边界见[完整记录](theme-first-visible-layout-2026-10-15.json)。

## 方法

Windows Release、Qt offscreen、960×900 图片；1/10/30 MiB 重复正文包含标题、粗体、斜体、删除线、行内代码和链接。每个新进程测量加载、主题快照、惰性准备、首次可见排版、首次/热绘制，再切走并切回两次，最后另建主题完整计算计数器作对照。计数器参考放在全部计时阶段之后，避免其分配提前干扰工作集。

主题固定为仓库 VLOOK Fancy Dark、安装目录的完整 Phycat Abyss（含 `phycat.dark.css`）和内置 GitHub CSS。运行前后核对 CSS、document-base 和 Phycat 两份字体的 SHA-256；原始 JSON 保存版本、路径、二进制与资源摘要。外部 Phycat 文件未复制到仓库，复现需要相同摘要的本机资源。VLOOK 的远程字体导入沿用现有离线处理，本轮不以网络字体完成下载为前提，也不代表跨机器字体像素一致。

修改前 VLOOK/GitHub 各尺寸两进程；Phycat 1 MiB 一个完整无详细 trace 样本。Phycat 10 MiB 在工作集达到约 15 GiB 后停止自有进程，已完成的阶段保留，整次不能视作验收；未尝试修改前 30 MiB。修改后三主题各尺寸两进程，共 18 份完整记录。另有修改前后各六份 1 MiB 详细阶段诊断，分开统计，不与关闭详细 trace 的时长混算。

这些是阶段微基准，不是 GUI 输入、窗口显示或键盘队列延迟。每组两个新进程不足以推断 p95/p99。详细 scopes 是包含子调用的墙钟时间，不能相加，也不是线程 CPU 时间。

## 修改

1. 最终行内样式按 owner/element 身份复用，通用元素样式也复用完整投影与交互配方；每类最多 2048 项，超限淘汰。不持有 AST 指针、不落盘。原有跨元素 CSS 值、样式投影和不可变交互配方共享继续生效。
2. 选择器的最后一段为后代/直接子代时，按祖先身份和编译选择器缓存其完整前缀结果，最多 8192 项。属性、结构、函数伪类仍用原匹配器；最后一段为兄弟关系时继续走完整匹配。缓存不把“相似属性”当作相同上下文。主题/媒体环境、结构失效时清空；稀疏节点回收时清理相应身份。
3. 修正计数器候选索引遗漏必要祖先标签的问题。`h3 > span::before` 不再让普通正文中的每个 Markdown `span` 参与扫描和 CSS 求值。只保存已确认的块/宿主标签；未构建的行内祖先、功能选择器和兄弟组合仍保守处理，HTML 保留完整发现路径。

文字替换仅在精确 CSS 语义签名与拓扑相同时保留缓存。HTML 属性、主题颜色/字体、媒体查询等变化会重新计算。没有修改换行和字体度量算法，也没有扩大布局失效范围；隐藏标签页沿用现有延后更新路径。本轮不宣称新增了任意主题间的整块排版共享。

没有从表中删除变慢样本。VLOOK 整体排版尚无稳定下降证据，不能把重复调用减少等同于总延迟已解决。

完整测试结束后，增加 **1 MiB × VLOOK/GitHub × 四轮**短测，每轮交替修改前/后执行顺序，共 16 个新进程。VLOOK 首次排版中位数 **76.42 → 71.87ms**，切回 **72.08 → 67.84ms**，首次绘制 **104.46 → 104.13ms**；GitHub 首次 **26.82 → 27.42ms**、切回 **25.29 → 24.14ms**。所有原始样本、计数器和像素/几何对照纳入 JSON 的 `interleaved_1MiB`。这组支持 VLOOK 小幅排版收益，但没有覆盖其大尺寸尾部，也不替代上述完整矩阵中仍有波动的结果。

1 MiB VLOOK 详细诊断中，首次排版 CSS 调用 **4908 → 3388**，实际新增 CSS 值计算仍为 **23**；通用元素样式调用 **1237 → 545**，交互配方调用 **1260 → 388**，样式投影调用 **2266 → 746**。第二份诊断的行内语义阶段 **17.84 → 10.88ms**，文字投影 **0.47 → 0.36ms**、换行与度量 **4.04 → 3.44ms**，完整首次排版 **93.74 → 76.69ms**。这些诊断数值说明减少了重复工作，不能替代上表关闭详细 trace 的结果。

中间版本额外启用 CSS 详细 scopes，首次排版中选择器匹配缺失累计约 **21.8ms**，最终值查找约 **5.4ms**、指纹约 **2.1ms**（相互包含）；因此继续优化祖先前缀复用，没有扩展指纹缓存或改动字体/换行。

字体选择/字号映射有独立的 `theme.fontForStyle` scope；后端成形、换行和行高度量合计在 `inline.wrapAndMetrics`。本轮没有进一步拆出 Qt 内部的纯字体度量耗时：这部分合计约 3–4ms，已确认的主要热点在样式查询与候选范围。

## Phycat 的独立热点

候选修复前，1 MiB 惰性主题准备 **2521.6ms**、工作集 **1635MiB**；修改后两次约 **305ms**、**124MiB**。10 MiB 已完成的修改前阶段为 **25671ms**，计数器工作 **584802**，CSS 调用 **3508811**；其后因内存停止，未作完整参考验证。修改后 10 MiB 准备约 **428ms**、工作集约 **430MiB**，30 MiB 准备约 **772ms**、工作集约 **1110MiB**，均完成两次切回及完整计数器对照。这是排除无关节点驻留的收益，不是压缩 AST，也不等同于释放整个进程的堆。

首次可见绘制仍慢：Phycat 约 **0.86–0.90 秒**，VLOOK 约 **0.10–0.12 秒**。它们不是本轮首次排版已解决的项目；后续应继续拆分绘制中的伪元素、效果和文本开销。

## 正确性与验收

主矩阵 18 份、详细矩阵六份修改后记录均通过完整计数器值与生成内容指纹对照。可用的相同尺寸修改前记录与修改后记录逐项比较像素 SHA-256、可见块几何、四个采样源位置的光标矩形和命中；全部一致。所有修改后进程两次切回的结果也与各自首次截图完全一致。10/30 MiB Phycat 缺少完整修改前记录，不冒充同尺寸前后对照。

新增产品回归覆盖普通文字重新绑定、行内视图回收、HTML 类名编辑、媒体条件往返、主题颜色/字号替换、继承下划线与交互配方，以及标题内计数器、嵌套行内祖先和兄弟组合。选择器回归对照独立新引擎，覆盖属性、位置、`:has()`、`:is()`、`:not()`、兄弟和作用域交互状态。

完整 Release 构建通过，全量 CTest **339/339** 全绿（**481.96 秒**），日志为 `build/first-layout-release-build.log`、`build/first-layout-all-ctest.log`。dist 已刷新，`Muffin.exe`、`MuffinCore.dll`、`MuffinUi.dll` 的 SHA-256 与 Release 一致，见 `build/first-layout-dist-hashes.json`。Python 语法、手动基准 C++ 格式和 `git diff --check` 通过。本轮不运行原生键盘矩阵，不 commit、不 push。
