# VLOOK 异步草稿、主题签名缓存与菜单查询复用（2026-10-15）

本轮实现[上一轮诊断](vlook-projection-queue-diagnostic-2026-10-15.md)确认的三个修复：草稿编码/提交移出 GUI，主题签名跨排版 pass 保留，六种行内格式菜单状态共享一次查询。三对正常/跳过草稿回调的原生 GUI 复测均有效；正常组确认草稿版本已保存，未再观察到输入被草稿 Timer 阻塞。

## 实现与正确性边界

`DraftSnapshotWriter` 为每个窗口提供一条惰性启动的串行 I/O 队列。GUI 捕获独立 `PieceTable`，共享 Qt 字符串/索引缓冲并复制 piece/prefix 向量，不在 GUI 展平全文。后台任务只使用副本，将 materialize、UTF-8 编码及正文/元数据提交全部移出 GUI。每个文档最多保留一个执行中的版本和一个最新待写版本；不同标签页共享队列，避免同时写入多份大文本。

成功提交后通过 GUI queued completion 确认 revision；失败可以重试。保存、丢弃、重载的清理同样排入队列，同时使旧任务/完成通知的 generation 失效，取消旧待写版本。清理 barrier 位于正在写入的旧任务之后，后续新编辑位于清理之后。任务不持有 session/tab/widget，窗口销毁会排空队列，因此不依赖退出后的 GUI 事件来收尾。

清理异步返回，正在提交的旧版本可以先落盘，再由排队的清理删除；正常关闭可能等待磁盘。强制结束尚未完成的写入/清理仍可能保留上一次恢复状态。正文和元数据沿用两个独立原子文件提交，不保证两文件事务。缓冲共享可能让后续输入复制已经增长的 append buffer；快照捕获还会复制 piece/prefix 向量，成本随碎片数增长。此次样例的编辑历史较短，不代表长编辑历史或存储异常的上限。

主题签名缓存保留源 `CssThemeSheet` 的 shared owner 和全局 mutation revision，不再在每次 `beginPass()` 清空。CSS 修改、同一地址赋值、主题切换都会失效；独立副本修改得到独立 revision。节点签名、几何约束、字体/图像资源 generation 仍使用原检查。没有添加磁盘缓存。

`CommandContextSnapshot` 一次捕获六个行内格式 flags，六个 checked predicate 共用结果；分类刷新也使用有作用域的快照。复用不跨刷新，不改变编辑命令本身的上下文解析。这轮未把所有编辑上下文永久缓存，也未合并剩余的图片/段落等查询。

## 原生 GUI 三对对照

本轮和上一轮均为 30 MiB × 1 页、Qt 6.11.1、Noto Serif 16 px、96 DPI/DPR 1、1100×820 窗口、1086×761 视口、屏幕报告 32 Hz，固定 VLOOK CSS SHA-256 为 `dc9ce7c464f4ddf8644040fb77c7c7e408a70f1bee3ba2c9f9a8ac746901f3cc`。沿用同一机器、设置隔离、动画、词数/菜单刷新及输入节奏。每个配置新进程顺序运行，期间不并发构建或测试；临时窗口置顶，并通过开始激活/结束激活和暴露检查。

首个运行 `build/async-draft-normal-1/` 在结束时失焦，排除且保留原数据。正式结果来自 `build/async-draft-normal-valid-{1,2,3}/` 与 `build/async-draft-control-{1,2,3}/`。正常组均在上下移动阶段确认 revision **82/82** 已保存；控制组只阻止临时草稿 Timer 信号，没有提交或确认草稿。

每个输入/方向键阶段 80 次、50 ms 间隔，滚动 80 次、100 ms 间隔，主题交替 12 次、1500 ms 间隔。独立线程投递合成 Qt 事件，完成时刻是 QWidget paint handler 返回，不是物理输入到显示器呈现。分位数使用 nearest-rank；80 次的 p99 为最大值。新增状态标记和细分计时会增加诊断开销，因此不把三次分位数混成总体保证。

[完整原始 JSON](vlook-async-draft-performance-2026-10-15.json)保留六组操作、时间线、作用域、工作集和按状态变化拆分的汇总。后台线程 perf 日志不进入 GUI 的采样容器或时间线，避免线程竞争与把 I/O 误算为 GUI 耗时；其完成版本保留在结果中。

## 内存和未解决范围

上下移动阶段正常组采样最大工作集约 **1401–1408 MiB**，控制组约 **1312–1314 MiB**；额外约 **90–95 MiB** 与一次后台全文展平/UTF-8 临时缓冲重叠。阶段结束后两者约 **1311–1319 MiB**。异步保存降低主线程阻塞，并非省内存；这些是 20 ms 工作集采样，不能当作精确堆大小或保证峰值。

冷滚动仍有同步构建/空闲回收，主题切换仍执行活动页全量更新；完整原始数据保留其耗时，本轮不把它们声明为已修复。长编辑历史的 append-buffer detach、严重碎片化快照捕获、关闭等待和存储失败等需要后续压力样例；已用可控阻塞写入和失败回调验证生命周期正确性。
