# 文档主题切换准备阶段：初始化、计数器和导航复用

日期：2026-10-16。Windows Release、Qt offscreen、960×900、DPR 1；三主题固定 CSS/字体，1/10/30 MiB。原始记录、资源/二进制摘要、异常与逐对校验见 [JSON](document-theme-preparation-2026-10-16.json)。

## 操作边界与诊断

旧阶段 `theme_switch_lazy` 实际是在新进程、新文档、新 `DocumentLayout` 上首次应用主题，不能代表已有文档每次切换的准备时间。保留旧阶段名以便对照，在本报告中称为“首次应用”。它不包含独立记录的 `theme_load`、`theme_snapshot`、首次可见排版和绘制。

新增 `--real-switch`：已有文档切走后保留新主题状态，切回从 detached prototype 开始，调用 `reuseDocumentSemantics`，对应 `EditorView::setTheme` 的文档语义交接。切回阶段包含便宜的 prototype/environment 复制和 Lazy rebuild；完整 ThemeManager 快照创建仍单列。旧的 selected snapshot 副本可能携带上次编号结果，不能替代这一操作。两种模型通过 `switch_model` 区分。主窗口只对活动页调用 `setTheme`，隐藏页继续保存 pendingTheme，激活后应用。

默认关闭的 scopes 拆分旧布局/索引释放、页面尺寸、builder 缓存/文档/设置、计数器、估高骨架、位置节点和文档索引；字体度量 miss 另列行高和平均字符宽度。详细 scopes 为 inclusive，不能相加当作总时间或 CPU 时间。

新进程首次估高中的 `estimate.lineHeight` 通常约 **276–312ms**，其中绝大部分属于第一次文字度量；切回仅 **0.1–0.2ms**。没有将这段一次性成本称作每次主题切换的热点，也没有通过移动计时边界宣称消除初始化。30 MiB 首次计数器约 **366–452ms**，真实切回约 **11–76ms**，两者分别测量。

## 实现与失效

- 未变文档的顶层/嵌套导航映射、位置 token 和 slot 存储与主题无关，按 document 地址、root NodeId、revision 和块数验证后复用。重置所有累计几何偏移并及时释放旧 layout/paint owner；字体、宽度、估高和可见块继续使用新主题计算。结构变化或文档重置不满足验证时完整重建。
- 精确 CSS 语义签名改为带长度边界的紧凑编码，保持全部原字段和树结构，普通字符仍不属于 CSS 语义。保留 inline HTML、href、任务状态、标题级别、代码语言、alert、表头等差异；使用 UTF-16 原始内容和可变长整数，不用可能碰撞的摘要替代等价判断。编码只在进程内使用，不写入磁盘。
- 已验证节点顺序/标识及文档版本的主题交接直接共享语义池和引用计数，避免逐块重哈希。负候选发现使用 intern 后的稳定字节地址作本次遍历内的形状身份。正候选继续独立计算 CSS、位置选择器、计数器作用域和生成内容；不跨主题复用编号程序或值。局部编辑修改池时 Qt 容器执行 copy-on-write，旧快照保持不可变。
- 修正 TOC 缓存只看 outline revision 的边界：更换文档 root 时也更新 outline，避免两个相同 revision 的文档显示上一个文档的目录。

30 MiB 详细切回：VLOOK 的位置 token 重建 **4.36ms**、嵌套索引 **3.52ms** 降至 scope 约 **0.001ms**；计数器 **75.87→56.86ms**。Phycat 计数器 **59.13→34.22ms**，GitHub **11.04→2.56ms**。这些单份详细数据用于定位；正式收益以下方无详细日志的重复矩阵为准。全篇估高仍约 **10–14ms**，未宣称完全消除文档遍历。
