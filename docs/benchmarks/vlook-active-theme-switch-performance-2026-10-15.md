# 活动页主题切换：投影缓存与文档语义复用

本轮定位并优化活动页主题切换；主题数据复用不包含旧主题的计数器输出或编辑页的 CSS 匹配缓存。详细对照见[四组诊断 JSON](vlook-active-theme-switch-diagnostic-2026-10-15.json)。

## 测量口径

Windows 原生 QPA，Qt 6.11.1，i7-10700、64 GiB RAM，Noto Serif 16px、96 DPI、DPR 1、屏幕报告刷新率 32 Hz。主题固定为仓库 VLOOK Fancy Dark，CSS SHA-256 为 `dc9ce7c464f4ddf8644040fb77c7c7e408a70f1bee3ba2c9f9a8ac746901f3cc`。窗口 1100×820，三页视口 1086×723；设置、文档和草稿目录隔离。

修改前后各用两个全新进程顺序测量 10 MiB × 三页；每轮包含输入、方向键、冷/热滚动、12 次间隔 1500ms 的主题动作、隐藏页首次激活、后续切页及切页后输入。原生窗口在检查点保持激活并暴露，无并发构建或测试；后台草稿正常启用。诊断详细 trace 开启，无截断，隐藏视口绘制及已记录的隐藏 EditorView Timer 事件均为零。

输入由独立线程按固定节奏投递 Qt 事件，不经过 Windows 实体输入派发；绘制结束指 QWidget paint 返回，不代表屏幕实际呈现。工作集每 20ms 采样，不代表堆大小或保证峰值。12 个样本的 p95/p99 等于最大值，不能推断总体长尾。每种目标的“首次”指测量阶段的首个动作；启动时已经加载过 VLOOK。

`summarize_theme_switch.py` 从原始样本复算同步、派发、绘制四类分位数，核对原始时钟、环境、输入数量、隐藏页与 trace 完整性，保留全部操作、主题时间线和逐次阶段。单次阶段为嵌套的包含时间，不能相加；阶段 CSS/计数器/布局/绘制总量另用排除子阶段后的独占时间。

## 稳定热点与对照结果

此前矩阵中的 10 MiB 三页约 1204ms 同步长尾，本轮修改前两次复测未复现：完整动作同步最大为 **590 / 641ms**，其中 `theme.apply` 最大 **579 / 631ms**。不能将原来那一次长尾认定为已定位到某个函数；本轮可重复定位的是下面的投影与计数器准备开销。

| 指标（10 MiB × 3 页） | 修改前两轮 | 修改后两轮 |
| --- | ---: | ---: |
| 主题动作同步 p95 | 590 / 641 ms | 271 / 243 ms |
| 计划到绘制 p95 | 667 / 685 ms | 377 / 289 ms |
| 重复 VLOOK 视口投影（逐次范围） | 144–191 ms | 2.3–4.0 ms |
| VLOOK 计数器块编译（逐次范围） | 169–216 ms | 26–42 ms |

| 主题阶段结束工作集 | 1394 / 1374 MiB | 1399 / 1398 MiB |

首次 Github 动作同步 **326/363 → 218/243ms**；首次测量阶段 VLOOK 动作 **570/641 → 203/200ms**。后续重复 Github **220–340 → 83–153ms**，重复 VLOOK **505–590 → 181–271ms**。缓存命中仍需独立 CSS 引擎、目标节点的计数器 CSS 和可见排版，不能将剩余成本理解为纯图片绘制。

首次视口绘制 scope 仍约 **9–73ms → 9–61ms**；本轮没有声称改善字体/效果绘制。保留全部诊断波动：修改后第一轮输入绘制 p95 **324ms**、后续切页 **333ms**，第二轮切页后输入 **283ms**；对应单次输入同步最大分别约 59/51ms，不能把排队或合并绘制等待直接视为同样长的排版调用。完整矩阵另外复测，详细 trace 结果不用于掩盖这些异常。

## 实现与边界

- `ThemeManager` 保存最多 8 个无文档主题原型，原型共享最多 4 个按精确视口、缩放、字号、暗色状态和源 revision 区分的投影。复用字体和已编译选择器，编辑页的可变引擎和匹配缓存保持独立。
- 原有主题清单内容摘要继续负责 CSS/import/图片/字体失效；同大小、同时间戳修改仍可检测。定义重新加载时清空准备缓存；所有缓存仅存于进程，不落盘。
- 同一文档、同一 revision 且对应块 NodeId 不变时，复用已有语义字节串，重新编译新主题计数器。临时 seed 在准备结束时释放，不保留一组历史主题文档快照。
- 完整准备中，仅对精确重复且无法包含计数器目标的块形状记忆负结果；正候选逐块独立处理，维持位置选择器、内联 HTML、嵌套计数器和生成内容。字体和几何变化仍通过正常布局计算；隐藏页继续延后到激活时更新。
- 回归覆盖环境/淘汰、CSS 内容失效、快照隔离、切换后普通编辑保留局部样式、嵌套 reset/set/increment、位置规则、生成内容和结构编辑后拒绝旧 seed。
