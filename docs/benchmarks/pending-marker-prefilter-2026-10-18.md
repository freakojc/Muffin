# 未完成 Markdown 标记收集：入口筛选

日期：2026-10-18。修改前基线：`69e47f26`。

## 改动与边界

`collectPendingMarkerOffsets()` 仅对可能包含未完成标记的 Paragraph 调用原识别函数。
筛选跳过前导 `QChar::isSpace()` 空白，保留井号、列表符号、反引号、波浪号、美元符号、反斜杠、引用符号和 `QChar::isDigit()` 数字开头的源文本。

筛选只排除不可能匹配的普通段落。候选继续使用原 `pendingMarkerStartInLine()`，保留单行、缩进、容器、分隔符和源码偏移规则；共享的 `detectPendingBlockMarker()` 与节点识别器未改动。仍递归访问所有子块，不添加逐节点缓存或额外常驻索引。

同步/异步打开和局部重解析共用这一收集入口；输入、Enter 提交及渲染继续使用原识别逻辑。布局估高、滚动锚点、总高度和第三方库没有新增修改。

## 性能对照方法

同一个 Release `/O2` Core 探针分别加载保存的修改前 DLL 与修改后 DLL；每份新进程先解析一个小预热文本，文件缓存温热。三轮正反交错，使用 1/10/30 MiB、完整 1 GiB 混合语法样例、有效未完成标记样例和候选密集样例。

样例使用 UTF-8/LF。有效标记样例在计时外执行与编辑场景一致的块降级，随后确实收集到 **4,000 个**偏移；不把已经加载为结构块的空标题算作段落标记。初次工具样例没有模拟降级且在 Windows 写成 CRLF，检查发现返回空集后已排除；原始试运行和探针保留在 `initial-positive-fixture/`，正式矩阵使用修正后的同一探针重跑。

记录解析、共享文本绑定、相对坐标、标记收集、文本索引与内存采样。首轮核对完整 AST/源码坐标/共享文本指纹，每轮核对节点统计、完整标记偏移数组摘要及文本索引汇总。探针内的指纹与节点遍历独立于阶段计时，但仍可能影响后续缓存状态。

## 正式结果

共 **36 份**独立进程样本；标记偏移摘要、节点统计、文本索引汇总及首轮完整 AST/源码坐标/共享文本指纹全部一致。以下为收集阶段三轮中位数，单位 ms：

| 样例 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 1 MiB 混合语法 | 6.32 | 0.12 |
| 10 MiB 混合语法 | 50.51 | 2.62 |
| 30 MiB 混合语法 | 168.48 | 7.40 |
| 1 GiB 混合语法 | **20,116.15** | **353.16** |
| 4,000 个有效标记 | 4.87 | 3.87 |
| 30,000 个候选段落 | 51.63 | 50.80 |

1 GiB 三份修改前样本为 **19,425.45 / 21,728.54 / 20,116.15 ms**，修改后为 **353.50 / 260.56 / 353.16 ms**，中位数减少 **98.24%**。全部保留，不仅选取最快的新样本。此混合语法样例没有未完成标记，适合入口筛选；候选密集样例接近原耗时，不据三轮小幅差异宣称普遍提速。

1 GiB 完整解析中位数 **24,823.59→24,912.65 ms**，没有对应改善；文本索引 **6,937.41→7,414.48 ms**，增加约 **477 ms**，保留这项变化，不宣称其他阶段统一下降。目标收集阶段的下降远大于这项增加，但阶段中位数不能直接拼成 GUI 首屏时间。

1 GiB 采样峰值私有提交前后均约 **11.89 GiB**；没有增加逐节点候选表，也不将本轮描述为内存优化。样例保留 **6,130,690** 个块和 **7,088,129** 个行内节点。
