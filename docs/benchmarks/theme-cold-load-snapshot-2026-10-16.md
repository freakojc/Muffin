# Phycat 冷主题加载与 VLOOK 快照创建

日期：2026-10-16。Windows Release、Qt offscreen、960×900、DPR 1。固定 VLOOK Fancy Dark、本机完整 Phycat Abyss 和内置 GitHub，沿用 1/10/30 MiB 文档。全部样本、资源和二进制摘要、排除原因与逐对校验见 [JSON](theme-cold-load-snapshot-2026-10-16.json)。

## 结论与计时边界

正式矩阵各十八个新进程，三主题 × 三尺寸 × 两轮；不打开详细 scopes。跨尺寸六份样本的中位数：

| 阶段 | 修改前 | 修改后 |
|---|---:|---:|
| Phycat 直接冷加载 | 656.17ms | 224.68ms |
| VLOOK 完整主题快照及视口投影 | 191.02ms | 85.05ms |
| VLOOK 直接冷加载 | 187.58ms | 114.39ms |

`theme_load` 是直接 `ThemeDefinition::fromCss()`，包含读取、导入、解析、字体准备/注册及原型样式映射；`theme_snapshot` 是 `RenderTheme::fromDefinition()` 加首次 `updateForViewport(960,900)`。两个阶段独立记录，不包含文档计数器、可见排版或绘制。冷加载指新应用进程，未清空 Windows 文件系统缓存。

真实 `ThemeManager` 入口另外测量，包含所选主题资源的严格内容校验。直接加载的约 225ms 不能代替主题管理器选择、取快照和投影的完整耗时。全部为 offscreen 阶段墙钟时间，不能替代真实 GUI 输入/显示验收。

## 热点与实现

### Phycat：大字体重复复制、校验和与摘要

Phycat 包含约 25 MiB 的中文字体。修改前详细样本直接加载 **673.69ms**，字体准备/注册 **599.40ms**，CSS 解析和选择器编译只有几毫秒。候选有效性检查先完整生成一份私有字体，注册时又生成；每张字体表复制后逐字节计算 SFNT 校验和，家族身份与注册键还重复计算整份字体 SHA-256。

通用字体路径现在：

- 先解码并验证所选候选的表目录、范围、名称与描述符，不为验证生成整张输出；一次计算解码字体的内容摘要。
- 未改动的大字形表在本次调用内使用只读视图，只有 name/head/OS2 等小表写入时分离；最终私有字体仍拥有完整独立字节。
- 校验和按四字节大端字读取，保持 32 位溢出与尾部补零规则；家族身份和注册键复用同一份内容摘要。
- 保留 WOFF/WOFF2 解码、私有族名、字重/斜体隔离、候选失败回退和 Qt 原有注册方式，不修改外部字体文件。未请求 CSS 描述符时，无 OS/2 的通用字体仍可使用。

最终详细样本字体阶段 **229.31ms**，校验和 **302.94→37.14ms**，私有字体处理 **327.11→44.53ms**。新增单次内容 SHA-256 scope 为 **171.96ms**；其他样本约 **126ms**，其波动和剩余成本保留。scopes 相互包含，不能相加或当作 CPU 时间。

### VLOOK：变量图与选择器复用

VLOOK 的大 SVG/data URI 自定义属性被众多原型元素继承。旧缓存检查位于扫描 `var()` 之后，没有引用的已计算变量图也不入缓存，因此相同大字符串不断重扫。中间定位样本的快照 **214.60ms**，变量计算 scope **81.86ms**、100 次调用。

变量缓存现在先匹配完整输入图或已计算输出图，再决定扫描和依赖求值；无引用的结果也缓存。仍为每线程最多 **16 项**、完整键值精确比较，覆盖循环、fallback、引号中的字面量、新增依赖和修改变量，未改为摘要或文件时间推断。

原型映射只计算选择器候选确实依赖的 hover/focus；伪元素与祖先交互依赖继续由通用状态索引判断。主题定义保留清除元素匹配缓存后的不可变编译模板，快照从模板创建独立缓存；媒体条件变化时重新建立活动规则、特征和候选索引，复用同一源码选择器的解析树。源码 revision 变化拒绝旧模板。编译池归属于主题/快照生命周期，不是无界进程全局缓存。

最终 VLOOK 详细快照 **99.69ms**，变量计算 **5.45ms**；原型 `css.finalLookup` **426→174 次**，编译 scope **48.33→11.14ms**、两次→一次，创建引擎 **29.27→2.34ms**。无详细日志的正式收益以下表为准。

## ThemeManager 的真实入口

额外前后各六个新进程，每主题两份，每进程两次重复选择。构造与列表扫描 **0.3–0.9ms**，仍不解析 CSS 或注册字体。`currentTheme()` 的首次构造和首次视口投影分开记录；内置 GitHub 初始化在两者之前、计时之外完成，避免误认为所选主题的重复成本。

| 主题 | 冷选择：前→后 | 首次快照：前→后 | 首次视口投影：前→后 |
|---|---:|---:|---:|
| VLOOK | 225.71 → 164.97 | 31.94 → 8.89 | 175.93 → 87.54 |
| Phycat | 1338.00 → 523.52 | 178.26 → 152.41 | 63.71 → 42.03 |
| GitHub | 26.54 → 21.47 | 1.45 → 0.73 | 18.92 → 15.91 |

这组样本较早期详细诊断的 Phycat 冷选择约 **945ms** 更慢，保留 **1325/1351ms** 原值，未单独确定额外等待的来源，不将全部前后差值归因于实现。VLOOK 新版冷选择两份 **120.60/209.34ms** 也完整保留。

修改后 Phycat 重复选择约 **147.66ms**、重复快照及投影 **145.29ms**；VLOOK 对应 **2.45/8.16ms**。复用前后 definition 的 sourceSheet 身份保持一致。Phycat 详细重复选择 **145.11ms** 中，内容校验占 **144.90ms**；重复快照 **146.48ms** 中校验占 **145.21ms**。冷选择还包含建立和验证资源清单各约 **149/143ms**。

严格内容校验仍覆盖 CSS、递归导入、字体和图片，包括同大小/同时间戳替换、缺失资源出现及删除。不以 mtime 缓存绕开失效保证；本轮没有解决每个公共查询重复校验大字体的开销。后续应先设计一次主题操作内的共享验证结果，再评估内容摘要实现，不将这些成本误认为 CSS 重新解析或快照重建。

## 显示、缓存与内存

正式十八对、详细三对、交错六对，每对三次快照，共 **81 组**前后像素摘要、块几何和四处光标矩形/命中完全相同。每份进程两次切回与首次相同；独立解码 **54 张**最终 PNG 并复算 BGRA SHA-256。全部文档基准完成独立全量计数器值与 generated-content fingerprint 对照。

新增字体回归使用独立逐字节参考算法，检查完整 SFNT 与各表校验和；增加超过 1 MiB 的无关表和四种尾长，覆盖溢出、源字节不可变、raw/prepared 注册身份一致及无 OS/2 的可选描述符。已有 native/fractional 与固定浏览器字体几何继续验证中英文、族别名、字重、斜体和回退。主题回归覆盖媒体环境、已计算变量、依赖新增/修改、源码 revision、缓存淘汰和旧快照不变。

不新增磁盘缓存。字体准备字节仅属于当前加载；持久部分仍是已有 Qt 字体注册及小型注册身份表。编译模板随主题定义保留，解析树与新环境共享；已匹配 DOM/AST、计算样式和可变文档状态不跨快照共享。变量缓存仍有固定条目上限。

30 MiB 最后一次切回绘制后的采样工作集（MiB）：VLOOK **1155.82→1163.55**，Phycat **1156.71→1158.37**，GitHub **1107.71→1107.15**。没有一致下降；VLOOK 增加约 **7.7 MiB**，包含新增编译模板驻留和分配器变化，未将它伪装成内存节省。这是阶段采样，不代表完整 GUI/草稿排空后的内存验收。
