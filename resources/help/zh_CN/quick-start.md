# 快速入门

欢迎使用 **Muffin**，一款使用 C++ 和 Qt 构建的快速、原生 Markdown 编辑器。

## 新建或打开文档

- 选择 **文件 → 新建** 创建一个空白文档，或选择 **文件 → 打开** 打开已有的 `.md` 文件。
- **文件 → 打开文件夹** 可在侧边栏打开一个文件夹，方便您浏览和切换文件。
- **偏好设置 → 文件 → 默认以标签页打开文件** 默认开启。从文件管理器或命令行打开文件时，会在已有窗口中打开标签页；关闭后会打开新窗口。「在新窗口打开」命令和命令行 `--new-window` 可单独指定新窗口。

## 两种编辑模式

- **渲染模式**（默认）显示实时格式化的页面 —— 输入 Markdown，即可看到效果。
- **源码模式** 显示原始的 Markdown 文本。可在 **视图** 菜单中切换。

## 编写您的第一份文档

输入 Markdown 即可即时格式化。以下是几个基本要素：

| 您输入的 | 您得到的效果 |
| --- | --- |
| `# 标题` | 一级标题 |
| `**粗体**` / `*斜体*` | **粗体** / *斜体* |
| `- 列表项` | 无序列表 |
| `` `代码` `` | 行内 `代码` |
| `[链接](https://example.com)` | 可点击的链接 |

您还可以插入表格、数学公式（`$E=mc^2$`）、脚注以及代码块 —— Muffin 支持渲染完整的 GitHub 风格 Markdown。

## 实用技巧

- 实时编辑模式粘贴网页或办公软件的 HTML 时，会保留标题、强调、列表、链接和表格。以制表符分隔的电子表格单元格会转换为 Markdown 表格。只需要文字时使用 **编辑 → 粘贴为纯文本**；代码块和源码模式始终按原始文字粘贴。
- 实时编辑模式复制时，同时提供适合富文本软件的 HTML 和适合 Muffin 的 Markdown。**偏好设置 → 编辑器** 可控制粘贴到纯文本软件时是否带 Markdown 语法。
- 在 **偏好设置 → 键盘快捷键** 中搜索命令、录入组合键、处理冲突或恢复默认设置。修改立即生效，下次启动仍然保留。
- 在 **偏好设置 → 导出 → PDF** 中配置页眉、页脚、作者和页码。模板支持 `${title}`、`${author}`、`${fileName}`、`${date}`、`${pageNo}`、`${pageCount}`。
- 使用菜单中的“格式”和“段落”命令为文本添加样式，无需记忆语法。
- **编辑 → 查找 / 替换** 可在当前文档中搜索。
- 在 **主题** 中挑选外观 —— Muffin 内置浅色、深色以及“Whitey”三种主题。

完整的语法参考请查阅 [Markdown 参考手册](help:markdown-reference)。
