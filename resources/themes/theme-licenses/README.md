# Theme sources and licenses

Bundled document themes are authored as plain CSS under `resources/themes/`.
A theme that ports another project's visual design carries its author's
attribution in the stylesheet header, and its license text in this folder.
The resource bundle embeds these notices so every build and export ships
them alongside the theme.

## Lengyi

- `lengyi.css` (light) and `lengyi-dark.css` (dark) port the visual design of
  the **Lengyi Markdown Editor**: <https://github.com/woyin2024/lengyi-markdown-editor>
- Copyright (c) 2026 冷逸 / 沃垠AI (Lengyi / Woyin AI).
- MIT License; full text in `Lengyi-MIT.txt`.
- The port re-expresses the original's design tokens (colour palette, type
  scale, spacing, code-panel treatment) for Muffin's document and chrome
  hosts. It does not copy the browser application's UI code.
